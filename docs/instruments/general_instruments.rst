General Instruments
-------------------

The following Instrument modules support I/O and analysis in
:py:mod:`GeospaceDataManagement`.


gdm_netcdf
^^^^^^^^^^^^
An instrument designed to load data previously saved as a NetCDF file.
See :ref:`api-gdm-netcdf` for more details on this instrument module.  A use
example is shown in :ref:`tutorial-files-load`.
